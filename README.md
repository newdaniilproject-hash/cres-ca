# vitrina

Мультиарендная платформа для украинских ФОПов: продавец получает витрину,
которая ощущается его собственным сайтом, админку и учёт; покупатель —
единый каталог товаров и услуг.

Стек: Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 ·
Supabase (Postgres, Auth, RLS, Storage) · Vercel.

```bash
npm install
npm run dev
```
