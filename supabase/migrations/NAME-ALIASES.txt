# Соответствие имён: как миграция называется В БАЗЕ → как называется ФАЙЛ.
#
# Зачем этот файл. Сверка `scripts/check-migrations.sh` сравнивает имена,
# отбросив ведущий номер. Обычно они совпадают дословно. Но у трёх миграций
# имя в журнале применённого и имя файла разошлись — так вышло при
# восстановлении потерянных файлов 11.08.2026: восстановленному файлу дали
# имя покороче, а строку в `supabase_migrations.schema_migrations` не трогали
# и трогать нельзя — это журнал факта, а не список пожеланий.
#
# Переименовывать файлы обратно тоже нельзя: на них ссылаются отчёты, тесты
# и комментарии в других миграциях. Поэтому расхождение объявлено явно здесь,
# по одной строке, а не спрятано послаблением в самой проверке. Послабление
# «пусть имена не сходятся, лишь бы количество совпало» скрыло бы ровно тот
# случай, ради которого проверка написана: одна миграция потеряна, другая
# лишняя, счёт сошёлся.
#
# Формат: <имя в базе> <пробел> <имя файла без номера и расширения>
# Строки с # и пустые пропускаются.
#
# Новую строку сюда добавляют ТОЛЬКО когда расхождение осознанное и объяснено.
# Если проверка ругается на миграцию, которой просто нет в репозитории, —
# это не повод дописать алиас, это повод положить файл.

modules_and_specialities   modules
move_citext_out_of_public  citext_schema
storage_buckets            storage
