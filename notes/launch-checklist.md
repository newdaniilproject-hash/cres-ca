## Что осталось на вас. Три вещи

**1. Проверить каналы связи.** Единственное, чего не видно из сессии:
переменные окружения Vercel. Проверяется действием, не чтением настроек.

- *Письма при регистрации.* Зарегистрировать тестовый аккаунт на второй
  адрес. Код пришёл → SMTP настроен. Нет → Resend как SMTP в Supabase
  (`smtp.resend.com:465`, пользователь `resend`, пароль — API-ключ).
- *Письма из очереди* (это ДРУГОЙ путь: регистрационные шлёт Supabase,
  уведомления — наш роут через Resend API). Завести расходник и ёмкость
  с ближним сроком, подождать 5 минут, посмотреть
  `select status, last_error from notification_outbox order by created_at desc`.
  `sent` → работает. `failed` → в ошибке написано, чего не хватает.
- *Пуши.* Приложение при старте пишет в лог Vercel, каких переменных нет,
  ПО ИМЕНАМ. Откройте логи первого запроса после деплоя — там готовый
  список.
- *Два тумблера в дашборде Supabase:* хук выдачи токена (право у роли
  выдано, сам тумблер из сессии не проверить) и Leaked password protection.

**2. Довести заведение.** Оно в статусе `draft`, витрина выключена,
0 материалов. Завершить онбординг и завести боевые данные салона: три
расходника с косметическим блоком, партии, ёмкости, чек-лист уборки,
техкарту. Без данных на устройстве проверять нечего — увидите пустые
экраны и не отличите «пусто» от «сломано».

**3. Запустить сборку.** Одна команда, см. блок 4 ниже.

**4.3. Запустить сборку тегом. Это то единственное, чего я сделать
не могу:** доступ этой сессии к репозиторию разрешает пуш веток и слияние
через API, но пуш ТЕГА отклоняется политикой (`HTTP 403`). Поэтому одна
команда за вами:

```
git fetch origin main && git tag android-v1 origin/main && git push origin android-v1
```

Начинать именно с Android: APK ставится на свой телефон сразу, без ревью
и без подписи, и отвечает на главный вопрос («открывается ли кабинет
у вошедшего») за минуты. iOS следующим — `ios-v1`... но тег `ios-v1`
и `ios-v2` на origin УЖЕ ЕСТЬ с прошлых попыток, поэтому для iOS брать
следующий свободный:

```
git tag ios-v3 origin/main && git push origin ios-v3
```

`play-v1` → `.aab` в Google Play, когда будет keystore в группе
`android_signing`.

Если тег не запустил сборку — значит вебхук в Codemagic не настроен.
Тогда: Applications → cres-ca → Start your first build → выбрать workflow
`android-apk` и ветку `main`.
